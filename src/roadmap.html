ChatWallet Roadmap

Our journey to a decentralized, sovereign future.

Phase 1

(Current)

Launch on EVM Networks & Core Features

  • Wallet & Chat: Launch of the core ChatWallet application on EVM-compatible networks, starting with a focus on Mantle.
  • P2P Communication: Integration of XMTP for secure, encrypted, and direct wallet-to-wallet messaging.
  • Identity: Implementation of Decentralized Identifiers (DIDs) via Ceramic for self-sovereign digital identity.
  • Privacy: Core functionality for Stealth Addresses, enabling private transactions off the public ledger.

Phase 2

Attestations & Token Launch

  • Attestations: Integration of Attestations to allow users to create and verify on-chain claims and build a web of trust.
  • Token Launch: Introduction of the native ChatWallet token to power the ecosystem, incentivize network participation, and facilitate governance.
  • Multisig: Release of multisignature wallet functionality, making it easier for groups and DAOs to manage shared funds.

Phase 3

SCA & Multichain Expansion

  • SCA Integration: Full implementation of Smart Contract Accounts (SCAs), including social recovery and gasless transactions for enhanced user experience.
  • Multichain: Expansion of multichain functionality to support a wider range of blockchain networks and assets.

Phase 4

Developer Ecosystem

  • API & SDK: Launch of a comprehensive Developer API and SDK to allow other decentralized applications to easily integrate ChatWallet's social-financial layer.
  • Ecosystem Growth: Focus on fostering a developer community and encouraging innovation built on the ChatWallet platform.
